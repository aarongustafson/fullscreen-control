Fullscreen Control via unpkg

Import the auto-registering definition module. See the README for the full API.

This demonstration follows @latest; pin a tested version in production. Without JavaScript or the CDN, native video controls still work. Use Escape or browser controls to exit fullscreen.

Automatic registration

<script type="module">
  import 'https://unpkg.com/@aarongustafson/fullscreen-control@latest/define.js?module';
</script>
<fullscreen-control button-text="Watch fullscreen">
  <video src="./sample.webm" controls
    aria-label="Moving circle"></video>
</fullscreen-control>

Silent clip: a circle moves left to right across a rectangle; no audio. Open the sample clip.
